# Premier-League-Dashboard

**English** | [繁體中文](README.zh-TW.md)

A Premier League dashboard for the 2026/27 season. It currently focuses on **Manchester United**, showing the last 5 finished matches and the next 3 upcoming ones.

This is a learning project: the backend uses Python to fetch data from the Premier League's Pulse API, and the frontend is a React dashboard.

## Features

- **Form summary**: wins / draws / losses, goals for and against over the last 5 matches
- **Finished matches**: score, goals (time, scorer, own goal / penalty), yellow and red cards
- **Upcoming matches**: opponent and kickoff time for the next 3 matches
- Man Utd is always shown on the left, with a home / away label
- Each card has a coloured left border for win (green) / draw (grey) / loss (red)
- Loading and error states

## Tech Stack

| Part | Uses |
|---|---|
| Backend | Python 3 (standard library only: `urllib`, `json`, `datetime`) |
| Data source | Premier League Pulse API (`footballapi.pulselive.com`) |
| Frontend | React 19 + Vite |

## Project Structure

```

├── backend/
│   └── premier_league.py        # Fetches the Pulse API and writes a JSON summary

        ├── App.jsx

        ├── Summary.jsx          # Form summary
        ├── MatchCard.jsx        # Single match card
        ├── matchUtils.js        # Shared helpers: home/away side, match result
        └── index.css
```

## Data Flow

```
Pulse API ──> backend/premier_league.py ──> frontend/public/man_utd_summary.json ──> React (fetch)
```

There is no API server yet. The Python script writes the JSON into `frontend/public/`, and React reads that file with `fetch`.

## Getting Started

Requires **Python 3** and **Node.js 18+**.

**1. Generate the data** (run from the project root, because the output path is relative)

```bash
python3 backend/premier_league.py
```

**2. Start the frontend**

```bash
cd frontend
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173 ).

> After re-running the Python script, press **Cmd + Shift + R** in the browser to force a reload, otherwise the page keeps the old data.

## JSON Format

```json
{
  "gameweek": 4,
  "kickoff": "Sun 13 Sep 2026, 16:30 BST",
  "status": "C",
  "home": { "team": "Man Utd", "score": 0 },
  "away": { "team": "Man City", "score": 1 },
  "goals": [{ "time": "60'00", "team": "Man City", "player": "Erling Haaland", "type": "G" }],
  "cards": [{ "time": "81'00", "team": "Man Utd", "player": "Harry Maguire", "card": "Y" }]
}
```

- `status`: `C` completed, `U` upcoming. `score` is `null` for upcoming matches
- `goals.type`: `G` goal, `O` own goal, `P` penalty
- `cards.card`: `Y` yellow, `R` red, `YR` second yellow (red)
